# DeskGarage web

TanStack Start app for the DeskGarage site. The landing page describes the desktop app and links to the Mac download. The web client will live in this same app.

```sh
pnpm dev:web
```

Portless serves the site at `https://desk-garage-web.localhost`. The page reads the newest GitHub release that includes Mac zip files. When that request fails, the download link goes to the releases list.

`src/route-tree.gen.ts` is generated by the TanStack Start plugin. Commit it so typechecking works immediately after checkout. Do not edit it by hand.
